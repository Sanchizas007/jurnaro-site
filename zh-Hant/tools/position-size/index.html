計算方式

部位 = 風險金額 ÷（進場到停損的距離 × 每手價格變動 1.0 的價值）。外匯標準手的這個價值是以報價貨幣計的 100,000；一股股票則是 1。請務必向券商確認合約大小。

這些計算機只是對你輸入的數字做運算，不是投資建議。交易之前，請對照券商的合約規格核對結果。
