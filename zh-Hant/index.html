它能做什麼

  • 十秒記錄一筆交易。快速模式：商品、方向和結果。完整模式：成交明細、加碼與減碼、手續費、停損與目標、標籤、筆記和圖表截圖。
  • 從任何券商匯入。帶上券商或平台匯出的 CSV，Jurnaro 會自己辨識欄位、日期和數字格式。免連結帳戶，免密碼。
  • 看清你的優勢。勝率、獲利因子、期望值、R 倍數、資金曲線與回撤，以及依星期、時段、商品、型態和錯誤劃分的成績。
  • 讓你守在規則之內。單日虧損、最大回撤、獲利目標和每日交易次數的上限，和自營交易公司挑戰賽的設定一樣，在你越線之前給出清楚的警告。
  • 會計算。部位大小、風險報酬比、點值、期望值、回撤恢復和複利，App 裡有，本站也免費提供。
  • 保持私密。沒有帳號，沒有廣告，沒有追蹤。備份到你選擇的資料夾，用 Face ID 上鎖，可匯出為 JSON、CSV 或 PDF。

免費計算機

六個在瀏覽器裡執行的計算機，免註冊：

  • 部位大小計算機算出該交易多少手或多少股，才能讓觸發停損時的虧損正好是你選定的帳戶比例。
  • 風險報酬比計算機比較你承擔的風險與可能賺到的利潤，並查看這筆交易損益兩平所需的勝率。
  • 點值計算機查看你交易的手數下，一點值多少，以貨幣對的報價貨幣計。
  • 期望值計算機把勝率、平均獲利和平均虧損換算成每筆交易的平均結果，以金額和 R 表示。
  • 回撤恢復計算機看看要把虧損賺回來需要多少報酬，以及為什麼深度回撤那麼難爬出來。
  • 複利計算機看看每月穩定的報酬，在有無追加投入的情況下，隨時間會成長到多少。

它不是什麼

Jurnaro 是一本日誌。它不連接券商，不下單，不發送訊號，不提供投資建議，也不保管資金。交易有虧損風險。Jurnaro 是獨立 App，與任何券商、交易所、自營交易公司或交易平台均無關聯。

訂閱方案
