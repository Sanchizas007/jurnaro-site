Comment ça marche

Gain nécessaire = drawdown ÷ (100 − drawdown). Une perte de 10 % demande 11,1 % pour être récupérée ; 50 % demandent 100 % ; 80 % demandent 400 %. C’est pourquoi limiter la taille d’une perte compte plus que la taille d’un gain.

Ces calculateurs font de l’arithmétique sur les nombres que vous saisissez. Ils ne constituent pas un conseil en investissement. Vérifiez le résultat avec les spécifications de contrat de votre courtier avant de trader.
